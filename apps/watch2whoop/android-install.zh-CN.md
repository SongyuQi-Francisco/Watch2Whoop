# 华为手机安装 Watch2Whoop（安卓安装包）

适用于 **HarmonyOS 4.x 及更早**（鸿蒙 2 / 3 / 4、EMUI 10 及以上）的华为手机。
纯血鸿蒙（HarmonyOS NEXT / 5 及以上，设置 → 关于手机里写「HarmonyOS 5」或更高）装不了这个安装包，以后会有单独的版本。

管理员会发给你两样东西：

1. **安装包**：一个 `.apk` 文件（例如 `watch2whoop-android-v1.0.7.apk`），或者它的下载链接；
2. **设置二维码** 或 **设置链接**（一段以 `watch2whoop://setup?` 开头的文字）。

## 第一步：允许安装这个安装包

1. 在手机上打开管理员发来的 `.apk`（微信里点文件 → 「用其他应用打开」→「文件管理」，或者用浏览器下载后点开）。
2. 如果提示 **「纯净模式」/「已开启纯净模式，禁止安装外部来源应用」**：
   - 有「仍然安装」或「继续安装」就点它；
   - 没有的话：打开 **设置 → 系统和更新 → 纯净模式 → 退出**（装好以后可以再打开）。
3. 如果提示 **「禁止安装来自此来源的应用」**：点 **设置**，把「文件管理」（或你用来打开安装包的应用、浏览器）的 **「允许安装应用」** 打开，再返回点安装。
   - 老一点的手机在：设置 → 安全 → 更多安全设置 → 安装外部来源应用。
4. 弹出 **「应用未经过检测」/「安全检测」** 时点 **「继续安装」/「仍然安装」**。这个应用不在华为应用市场上架，所以会有这个提示。
5. 装好后桌面上会出现 **Watch2Whoop** 图标。

## 第二步：用设置二维码登录

1. 打开 Watch2Whoop。
2. 点 **「我有设置链接」**。
3. 二选一：
   - **扫码**：点 **「扫描设置二维码」**，第一次会问能不能用相机，点「允许」，然后对着管理员给你的二维码（在别人手机或电脑屏幕上、打印出来的都行）。
   - **粘贴**：如果设置链接是发到你这台手机上的（比如微信），长按那段文字 → 复制，回到 Watch2Whoop 点 **「粘贴设置信息」**。
     （二维码就在这台手机屏幕上时扫不了自己，用这个办法。）
4. 显示「设置好了」后点 **「打开今天页」**，会自动登录。

> 设置二维码 / 链接里的登录码只能用一次、几天后过期；用过或过期了请找管理员重新要一个。只发给本人，不要转发。

## 用起来

- **今天 / 趋势 / 饮食 / 记录 / 我** 五个页面、和 AI 对话（Jarvis）都能用。
- **按住说话**：第一次按 🎤 时手机会问能不能用麦克风，点「允许」。点了「禁止」的话，页面会出现「打开设置」，在 **权限 → 麦克风** 里打开。
- **拍照记餐 / 发照片给 AI**：点相机按钮会直接打开相机（第一次问相机权限）；点照片按钮可以从图库选，也可以选「相机」现拍。
- 系统语言是中文就显示中文，英文就显示英文；也可以在「我」→ 个人资料里改。
- 手机的返回键 / 返回手势：先在今天页里返回上一页，到头了再退出 app。

## 暂时还不能用

- **华为手表的数据还不能同步**（「我」→「手机同步」里写着「华为手表数据接入开发中」）。在做了，做好后更新 app 就有。
- **通知推送**：暂时没有（华为手机没有谷歌服务）。
- 「通过 Apple 登录」只有苹果手机有。

## 更新

管理员发来新的 `.apk` 后，直接打开安装（选「更新」/「安装」），**不用卸载**，登录和设置都会保留。

如果安装时提示 **「签名不一致」/「与已安装的应用冲突」**：说明你装的是测试版，先卸载旧的 Watch2Whoop，再装新的，然后按第二步重新扫码登录（服务器上的数据不会丢）。

## 卸载

长按桌面图标 → 卸载。服务器上的数据不受影响；要删除账号请在 app 里「我」→「删除账号」。
